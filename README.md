# Telegram Auto-Ban Bot

A lightweight Telegram bot that automatically blacklists subscribers who leave your channel.

## Quick Setup
1. Create a bot with `@BotFather` on Telegram and obtain your API Token.
2. Add the bot to your Telegram Channel as an **Administrator** with **Ban Users** (or Manage Members) enabled.
3. Deploy to Railway:
   - Connect your GitHub repository.
   - Add the environment variable: `BOT_TOKEN = <your_token>`.
